## Alkoholer (-ol)

1. Lengste kjede som **inneholder C–OH**; alkan + **-ol**.
2. Nummerer slik at **OH får lavest lokant** (OH slår flerbindinger og alkylgrupper ved nummerering).
3. Flere OH: **-diol, -triol** (etan-1,2-diol, propan-1,2,3-triol).
4. Høyere prioritert gruppe til stede → **hydroksy-**.
5. Med dobbeltbinding: alk-**en**-ol, f.eks. but-3-en-2-ol, (3R,4E)-hept-4-en-3-ol.

| Struktur | Navn |
|---|---|
| CH₃–CH₂–OH | etanol |
| CH₃–CH₂–CH₂–OH | propan-1-ol |
| CH₃–CH(OH)–CH₃ | propan-2-ol |
| HO–CH₂–CH₂–CH₂–OH | propan-1,3-diol |
| HO–CH₂–CH(OH)–CH₃ | propan-1,2-diol |
| (CH₃)₃C–OH | 2-metylpropan-2-ol |

:::feil
Et forelesningslysbilde navngir HO–CH₂–CH₂–CH₂–OH som «propan-1,2-diol». Det er en skrivefeil: OH sitter på C1 og C3 → **propan-1,3-diol**. Kollokvium: «3-propanol» finnes ikke – det er propan-1-ol tegnet fra andre enden.
:::

```smiles-row
OCCCO | Propan-1,3-diol
CC(O)CO | Propan-1,2-diol
CC(O)C=C | But-3-en-2-ol
```

## Etere (alkoksyalkaner)

1. **Lengste** karbonkjede = stamalkan.
2. Den korte gruppen + O = **alkoksy-**: metoksy (–OCH₃), etoksy (–OC₂H₅), propoksy.
3. Laveste lokant for alkoksygruppen; alfabetisk med andre prefikser.

| Struktur | Navn |
|---|---|
| CH₃–O–CH₃ | metoksymetan |
| CH₃–O–CH₂CH₂CH₃ | 1-metoksypropan |
| CH₃–O–CH(CH₃)₂ | 2-metoksypropan |
| C₂H₅–O–CH₂CH₂F | 1-etoksy-2-fluoretan |
| C₂H₅–O–C₂H₅ | etoksyetan (dietyleter) |

**Sykliske etere:** syklo-alkan med **oksa-** for ring-O; O teller med i ringstørrelsen: **oksasykloheksan** (= tetrahydropyran), 4-fluoroksasykloheksan. Mange har trivialnavn: oksiran (etylenoksid), tetrahydrofuran, 1,4-dioksan.

```smiles-row
COC(C)C | 2-metoksypropan
CCOCCF | 1-etoksy-2-fluoretan
FC1CCOCC1 | 4-fluoroksasykloheksan
```

## Tioler (-tiol)

- Alkannavn + **-tiol**: metantiol, etantiol, propan-1-tiol, but-2-en-1-tiol.
- Prefiks: **sulfanyl-** (bis(sulfanyl) for to). Prioritet under alkohol, over amin.

## Aminer (-amin)

1. **Primære** (RNH₂): alkannavn + **-amin** med lokant: etanamin, **propan-2-amin**, sykloheksanamin.
2. **Sekundære/tertiære**: største alkylgruppe gir stamnavnet; de andre gruppene på N får prefikset **N-**: CH₃CH₂CH₂–NH–CH₂CH₃ = **N-etylpropan-1-amin**; CH₃CH₂CH₂–N(CH₃)₂ = **N,N-dimetylpropan-1-amin**.
3. Som substituent: **amino-** (2-aminopropansyre, 3-aminopropansyre).

```smiles-row
CC(C)N | Propan-2-amin
CCCNCC | N-etylpropan-1-amin
CCCN(C)C | N,N-dimetylpropan-1-amin
```

## Arbeidede eksempler

:::eksempel[Struktur → navn: CH₃–CH(CH₃)–CH₂–CH(OH)–CH₃]
1. Kjede med C–OH: 5 C (pentan).
2. OH lavest: fra høyre → OH på C2, metyl på C4.
3. **4-metylpentan-2-ol**.
:::

:::eksempel[Struktur → navn: CH₂=CH–CH₂–CH₂–OH]
OH bestemmer nummereringen (suffiks): OH på C1 → C=C mellom C3 og C4 → **but-3-en-1-ol**.
:::

:::eksempel[Eksamenstype h2024: CH₃–CHCl–CH₂–CH₂–CH(OH)–CH₂–CH₃]
1. Hovedgruppe OH → suffiks -ol; Cl er alltid prefiks.
2. Kjede 7 C; OH lavest fra høyre → OH på C3, Cl på C6.
3. **6-klorheptan-3-ol** (eldre: 6-kloro-3-heptanol – alternativ på h2024). Fellene: «2-kloro-5-heptanol» nummererer etter Cl i stedet for OH; «3-hydroxy-2-kloroheptan» gjør OH til prefiks selv om den er hovedgruppen.
:::

:::eksempel[Navn → struktur: 2-metoksybutan]
Butan, –OCH₃ på C2 → CH₃–CH(OCH₃)–CH₂–CH₃.
:::

```smiles-row
CC(C)CC(C)O | 4-metylpentan-2-ol
OCCC=C | But-3-en-1-ol
CCC(C)OC | 2-metoksybutan
CC(Cl)CCC(O)CC | 6-klorheptan-3-ol
```

:::eksamen
Øvingsoppgaver/eksamen: «1-metoksypropan» (eter), «propan-2-ol / propanon» (oksidasjonsoppgaver), tiolnavn (h2025: «3-buten-1-tiol» vs «2-buten-1-tiol» – tell fra SH-karbonet). v2024: alternativer som «1-metyl-2-pentanol» (ugyldig – metyl på C1 forlenger kjeden: heksan-2-ol) og «2-etyl-4-pentanol» (ugyldig – feil kjede og nummerering) er typiske feller. Primær/sekundær/tertiær klassifisering henger tett sammen med navnet: propan-1-ol (1°), propan-2-ol (2°), 2-metylpropan-2-ol (3°).
:::

## Test deg selv

:::sjekk[Navngi CH₃–CH₂–O–CH₂–CH₂–CH₂–CH₃.]
1-etoksybutan. Butyl er den lengste kjeden (stamme), etoksy på C1.
:::

:::sjekk[Hvorfor er «2-butanol» og «butan-2-ol» samme stoff?]
Det er eldre og nyere skrivemåte for samme struktur (CH₃CH(OH)CH₂CH₃). IUPAC anbefaler nå at lokanten står rett foran endelsen den gjelder.
:::

:::sjekk[Navngi (CH₃CH₂)₂N–CH₃.]
N-etyl-N-metyletanamin. Største gruppe er etyl → etanamin; den andre etylgruppen og metylgruppen på N får N-prefikser, alfabetisk.
:::

:::sjekk[Tegn 3-metylbutan-2-ol og klassifiser alkoholen.]
CH₃–CH(OH)–CH(CH₃)–CH₃. OH-karbonet (C2) har to C-naboer → sekundær alkohol.
:::
