## Karboksylsyrer (-syre)

1. Lengste kjede med –COOH; **COOH-karbonet = C1** (ingen lokant).
2. Alkan + **-syre** (eng. -oic acid): propansyre (propanoic acid).
3. Substituenter etter vanlige regler: **3-metylbutansyre**, **2-hydroksypropansyre**.
4. To COOH: **-disyre** (etandisyre = oksalsyre; butandisyre = ravsyre). Forelesningen skriver «1,2-etandisyre» – lokantene er strengt tatt overflødige når COOH sitter i begge ender.
5. COOH på ring: **-karboksylsyre** (sykloheksankarboksylsyre); benzosyre er beholdt navn.
6. Høyest prioritet av alle → alltid suffiks.

Trivialnavn verdt å kjenne: maursyre (metansyre), eddiksyre (etansyre), melkesyre (2-hydroksypropansyre), pyrodruesyre (2-oksopropansyre).

## Anioner og acylgrupper

- **Karboksylat**: -syre → **-oat**: etanoat (acetat), propanoat, butanoat, laktat, 2-oksopropanoat (pyruvat).
- **Acylgruppe** R–C(=O)– : -syre → **-oyl**: etanoyl (acetyl), propanoyl, benzoyl. Brukes i navn som 2-(etanoyloksy)benzosyre (aspirin).

## Estere (alkyl-alkanoat)

1. Del esteren ved O–C(alkyl)-bindingen.
2. **Alkoholdelen** (R′ bundet til O) → **alkyl**, skrives først.
3. **Syredelen** (inkl. karbonyl-C) → **-oat**, nummereres fra karbonyl-C.
4. Norsk: ofte i ett ord – **etylbutanoat**, **etylpropanoat**, metyletanoat.

| Struktur | Navn |
|---|---|
| CH₃COOCH₂CH₃ | etyletanoat (etylacetat) |
| CH₃CH₂COOCH₂CH₃ | etylpropanoat |
| CH₃CH₂CH₂COOCH₂CH₃ | etylbutanoat |
| HCOOCH₃ | metylmetanoat |
| CH₃COOCH₃ | metyletanoat (metylacetat) |

## Amider (-amid)

1. Syrenavn: -syre → **-amid**: etanamid (acetamid), butanamid, benzamid.
2. Alkylgrupper på N: prefiks **N-** (én for hver gruppe), alfabetisk: **N,N-dimetylpropanamid**, **N-etyl-N-metyletanamid**, **N-metylacetamid**.

```smiles-row
CC(C)CC(=O)O | 3-metylbutansyre
CCC(=O)OCC | Etylpropanoat
CCC(=O)N(C)C | N,N-dimetylpropanamid
OC(=O)C1CCCCC1 | Sykloheksankarboksylsyre
```

## Arbeidede eksempler

:::eksempel[Struktur → navn: CH₃–CH₂–CH₂–C(=O)–O–CH₃]
1. O–alkyl: CH₃ → **metyl**.
2. Syredel: 4 C inkl. C=O → butansyre → **butanoat**.
3. **Metylbutanoat**.
:::

:::eksempel[Struktur → navn: CH₃–C(=O)–NH–CH₂CH₃]
Syredel 2 C → etanamid; etyl på N → **N-etyletanamid** (N-etylacetamid).
:::

:::eksempel[Navn → struktur: propyletanoat]
Propyl fra alkoholen (propan-1-ol), etanoat fra eddiksyre: CH₃–C(=O)–O–CH₂CH₂CH₃.
:::

:::eksempel[Navn → struktur: 2-aminobutansyre]
Butansyre med NH₂ på C2: CH₃CH₂–CH(NH₂)–COOH (en α-aminosyre).
:::

```smiles-row
CCCC(=O)OC | Metylbutanoat
CC(=O)NCC | N-etyletanamid
CC(=O)OCCC | Propyletanoat
CCC(N)C(=O)O | 2-aminobutansyre
```

:::eksamen
v2026 (kortsvar): CH₃CH₂COOH → **propansyre** (sensor: «karboksylsyre, og syre legges til alkannavnet»). h2024: «Butanamid» blant butanoyl/butansyre/butanoat. h2023: tre syrer → propansyre, 3-metylbutansyre, 2-hydroksypropansyre (fellene «1-propansyre», «2-metylbutansyre», «hydroksy-2-propansyre»); skill karboksylsyre/ester/amid på figur. v2025: «etylbutanoat» (ikke «etylbutansyre/etylbutanoyl/etylbutanamid»). h2025: alternativer som «propankarboksamid», «hydroksymetylacetat», «etylformaldehydsyre», «3-aminopropansyre» – strukturen var H₂NCH₂CH₂COOH, riktig svar **3-aminopropansyre** (COOH gir suffikset, NH₂ blir amino-). Øvingsoppgaver: 3-metylbutansyre, etylpropanoat, *N,N*-dimetylpropanamid.
:::

:::feil
- Ester: delen bundet til **karbonyl-C** er «-oat»; delen bundet til **O** er «alkyl». Ikke bytt om.
- Karbonyl-C telles med i syredelen: CH₃COO– er etanoat (2 C), ikke metanoat.
- I amider gjelder *N*-lokanten nitrogenet, ikke et C-nummer.
:::

## Test deg selv

:::sjekk[Hva heter esteren dannet av butansyre og metanol?]
Metylbutanoat: CH₃CH₂CH₂COOCH₃.
:::

:::sjekk[Navngi CH₃CH₂CH₂C(=O)NH₂ og CH₃CH₂C(=O)N(CH₃)CH₂CH₃.]
Butanamid; *N*-etyl-*N*-metylpropanamid.
:::

:::sjekk[Hva er IUPAC-navnet på HOOC–CH₂–CH₂–COOH?]
Butandisyre (ravsyre; anionet heter succinat/butandioat).
:::

:::sjekk[Gi et systematisk navn på aspirin og forklar oppbygningen.]
2-(etanoyloksy)benzosyre (2-acetyloksybenzosyre). Benzosyre er hovedgruppen; på C2 sitter en esterbundet acetylgruppe, –O–C(=O)CH₃ (etanoyloksy).
:::
