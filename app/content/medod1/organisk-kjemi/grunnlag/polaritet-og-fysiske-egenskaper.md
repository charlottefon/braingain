## Polare bindinger

En binding er polar når atomene har ulik elektronegativitet. I organiske molekyler er C–H og C–C praktisk talt upolare, mens bindinger til **O, N og halogener** er polare (Cδ⁺–Oδ⁻, Cδ⁺–Nδ⁻, Cδ⁺–Xδ⁻). Et molekyl med polare grupper får en permanent dipol.

## Intermolekylære krefter (svakest → sterkest)

Teorien bak kreftene: [Intermolekylære krefter (generell kjemi)](/medod1/generell-kjemi/teori/intermolekylaere-krefter).

| Kraft | Finnes i | Øker med |
|---|---|---|
| London-dispersjonskrefter | **alle** molekyler (eneste kraft i alkaner) | større molekyl, større kontaktflate (lange, uforgrenede kjeder) |
| Dipol–dipol | polare molekyler: aldehyder, ketoner, estere, etere, halogenalkaner | sterkere dipol |
| Hydrogenbindinger | molekyler med **H bundet til O eller N** (donor) + ledig elektronpar på O/N (akseptor) | antall donorer og akseptorer |

:::husk
**Donor vs akseptor:** Bare O–H og N–H kan *donere* hydrogenbinding. Karbonyl-O, eter-O og amin-N kan *akseptere*.
- Alkoholer, fenoler, karboksylsyrer, primære/sekundære aminer og amider: donor **og** akseptor.
- Etere, aldehyder, ketoner, estere, tertiære aminer og *N,N*-disubstituerte amider: **bare akseptor** – kan ikke H-binde til hverandre, men kan H-binde til vann.
:::

## Kokepunkt – hvordan rangere

1. **H-bindinger mellom molekylene?** Ja → høyt kokepunkt. Flere H-bindinger (amid > syre > alkohol) → høyere.
2. **Polar gruppe uten O–H/N–H?** Dipol–dipol → middels.
3. **Bare C og H?** Kun London → lavest.
4. Innenfor samme klasse: **større molekyl** → høyere; **forgrening** → lavere (mindre kontaktflate).

Typisk rekkefølge for forbindelser med omtrent lik molmasse:

**alkan < eter < aldehyd/keton ≈ ester < amin < alkohol < karboksylsyre < primært amid**

| Sammenligning | Forklaring |
|---|---|
| Butan (−0,5 °C) < propanon (56,1 °C), lik molmasse | propanon har permanent dipol (C=O) i tillegg til London |
| Metoksyetan < propan-1-ol (begge C₃H₈O) | alkoholen kan donere H-bindinger, eteren bare akseptere |
| Amin < tilsvarende alkohol | N–H···N er svakere enn O–H···O (O er mer elektronegativ) |
| Etanol (78 °C) < eddiksyre | syrer danner sterke H-bundne dimerer; selv maursyre koker ved 101 °C |
| Eddiksyre < **acetamid** | primære amider har to N–H-donorer + C=O-akseptor → nettverk av H-bindinger |
| *N,N*-dimetylacetamid < acetamid | tertiært amid har ingen N–H → ingen H-binding mellom molekylene |
| Ester < karboksylsyre | ester har ingen O–H |
| 2,2-dimetylpropan < pentan (C₅H₁₂) | forgrening → mindre overflate → svakere London-krefter |
| Heptan < 1-heptanol | OH gir H-bindinger |

```smiles-row
CCCCC | Pentan (kp 36 °C)
CC(C)(C)C | 2,2-dimetylpropan (kp 9,5 °C)
```

:::eksamen
Kokepunkt spørres nesten hvert år:
- h2025: «Hvilket av eddiksyre, acetamid, *N,N*-dimetylacetamid og etanol har høyest kokepunkt?» → **acetamid**.
- h2025: 2-metylheksan, 1-heptanol, heptan, 1-hepten → **1-heptanol**; og «2,2-dimetylpropan har lavere kokepunkt enn pentan» (riktig).
- v2026: «Hvorfor har alkoholer høyere kokepunkt enn alkaner med tilsvarende molekylvekt?» → H-bindinger mellom molekylene.
- h2023: «Amin har høyere kokepunkt enn amid» er **feil**; høyest kokepunkt av propanol, propylamin, metylester og butan → **propanol**.
- v2024: høyest kokepunkt av eddiksyre, butan, metylester og *N*-metylacetamid → ***N*-metylacetamid** (sekundært amid: N–H-donor + sterk C=O-akseptor).
- v2023: nonan, propan, heptan, metan → **nonan** (lengst kjede). v2025: «kokepunktet til alkaner synker med økende kjedelengde» – feil.
:::

## Vannløselighet

- «Likt løser likt»: polare grupper som kan H-binde til vann (OH, NH₂, COOH, C=O) gir løselighet; karbonkjeden er hydrofob.
- Korte alkoholer, aldehyder, ketoner og syrer er godt vannløselige; **løseligheten faller når karbonkjeden blir lengre**. Egenskapene bestemmes av balansen mellom hydrofil gruppe og hydrofobt karbonskjelett.
- Alkaner er uløselige i vann (hydrofobe).
- Ioniske former (karboksylat R–COO⁻, ammonium R–NH₃⁺) er langt mer vannløselige enn de nøytrale formene – viktig for legemidler og aminosyrer.

## Andre fysiske effekter

- **Rettkjedede alkaner**: kokepunkt og smeltepunkt stiger jevnt med kjedelengden (London-krefter).
- **Cis/trans**: *cis*-but-2-en (kp 3,7 °C) og *trans*-but-2-en (kp 0,3 °C) har ulike fysiske egenskaper – de er diastereomerer.
- **Enantiomerer** har *identiske* kokepunkt, smeltepunkt og løselighet (unntatt optisk aktivitet), se [Enantiomerer, diastereomerer og meso](/medod1/organisk-kjemi/grunnlag/enantiomerer-diastereomerer-meso).

:::feil
- «Forgrening øker kokepunktet» – feil, forgrening senker det.
- «Aldehyder og ketoner danner H-bindinger med hverandre som alkoholer» – feil; de kan bare *akseptere* H-bindinger (fra vann eller alkoholer).
- «Karboksylsyrer har høyest kokepunkt av alt» – primære amider ligger ofte høyere.
:::

## Test deg selv

:::sjekk[Ranger etter stigende kokepunkt: propan-1-ol, butan, propanon, eddiksyre (omtrent lik molmasse 58–60).]
Butan (kun London) < propanon (dipol–dipol) < propan-1-ol (H-bindinger) < eddiksyre (sterke H-bindinger, dimerer).
:::

:::sjekk[Hvorfor har *N*-metylacetamid høyere kokepunkt enn *N,N*-dimetylacetamid?]
Det monosubstituerte amidet har fortsatt én N–H som kan donere hydrogenbinding til C=O i nabomolekyl. Det disubstituerte amidet mangler N–H og kan bare akseptere – ingen H-binding mellom egne molekyler.
:::

:::sjekk[Hvorfor er etanol blandbart med vann, mens heksan-1-ol er dårlig løselig?]
Begge har én OH som kan H-binde til vann, men i heksanol dominerer den lange hydrofobe karbonkjeden. Jo større hydrofob del, desto lavere vannløselighet.
:::

:::sjekk[Pentan og 2,2-dimetylpropan har samme molekylformel. Hvorfor har pentan høyere kokepunkt?]
Begge har bare London-krefter. Den rette kjeden i pentan gir større kontaktflate mellom molekylene enn det kompakte, kuleformede 2,2-dimetylpropan → sterkere dispersjonskrefter → høyere kokepunkt.
:::
