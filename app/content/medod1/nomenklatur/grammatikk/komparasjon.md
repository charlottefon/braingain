## Tre grader

| Grad | 1+2-adjektiv | 3.-dekl.-adjektiv | Bøyes som |
|---|---|---|---|
| **Positiv** | *longus, a, um* (lang) | *brevis, e* (kort) | grunnformen |
| **Komparativ** | *longior, longius* (lengre) | *brevior, brevius* (kortere) | **3. deklinasjon** (m+f *-ior*, n *-ius*, gen *-ioris*) |
| **Superlativ** | *longissimus, a, um* (lengst) | *brevissimus, a, um* (kortest) | **1+2** |

Dannelse: stammen (gen sg minus endelsen, *long-*, *brev-*, *grav-*) + ***-ior/-ius*** (komparativ) eller + ***-issimus*** (superlativ).

Ordlisten: *brevior/ius, ioris, 3* – *brevissimus, 1+2*; *gravior/ius, ioris, 3* (tyngre, alvorligere) – *gravissimus, 1+2*; *longior/ius, oris, 3* – *longissimus, 1+2*; *latus, 1+2* (bred) – *latissimus, 1+2* (bredest).

:::feil
Forelesningsnotatet (02.–03.11) har noen glipper i oversettelsene: der står *longior* = «bredere», *brevior* = «alvorligere, tyngre», og *brevissimus* er markert «3». Riktig er *longior* = **lengre**, *brevior* = **kortere** (som i ordlisten), og ***brevissimus* bøyes som 1+2**, slik alle superlativer gjør.
:::

## Bøyning av komparativ

Komparativ bøyes etter 3. deklinasjon, men **ikke som i-stamme**: abl sg ***-e***, n pl ***-a***, gen pl ***-um***.

| Kasus | longior (m+f) | longius (n) |
|---|---|---|
| Nom sg | long**ior** | long**ius** |
| Akk sg | long**iorem** | long**ius** |
| Gen sg | long**ioris** | long**ioris** |
| Abl sg | long**iore** | long**iore** |
| Nom pl | long**iores** | long**iora** |
| Akk pl | long**iores** | long**iora** |
| Gen pl | long**iorum** | long**iorum** |
| Abl pl | long**ioribus** | long**ioribus** |

:::husk
**m+f *-ior*, n *-ius*.** *ligamentum posteri**us***, *ganglion superi**us***, *cornu anteri**us*** (n), men *ramus posteri**or***, *arteria cerebri anteri**or*** (m/f). Endelsen *-ius* i komparativ er altså **intetkjønn**, ikke hankjønn, selv om den ligner *-us*.
:::

## Posisjonsuttrykk

Komparativ brukes svært ofte i anatomiske **posisjonsuttrykk**:

| m+f / n | Norsk | Eksempel |
|---|---|---|
| *superior / superius* | øvre | *ganglion superius* (øvre nerveknute) |
| *inferior / inferius* | nedre | *ganglion inferius* |
| *anterior / anterius* | fremre | *ramus anterior nervi spinalis*; *cornu anterius* |
| *posterior / posterius* | bakre | *arteria cerebri posterior*; *ligamentum posterius* |
| *interior / interius* | indre | |
| *exterior / exterius* | ytre | |

| Kasus | ganglion superius (2n + n) | arteria posterior (1f + f) |
|---|---|---|
| Nom sg | ganglion superius | arteria posterior |
| Akk sg | ganglion superius | arteriam posteriorem |
| Gen sg | ganglii superioris | arteriae posterioris |
| Abl sg | ganglio superiore | arteria posteriore |
| Nom pl | ganglia superiora | arteriae posteriores |
| Akk pl | ganglia superiora | arterias posteriores |
| Gen pl | gangliorum superiorum | arteriarum posteriorum |
| Abl pl | gangliis superioribus | arteriis posterioribus |

## Uregelmessig komparasjon

| Positiv | Komparativ | Superlativ |
|---|---|---|
| *magnus, a, um* (stor) | *maior, maius* (større) | *maximus, a, um* (størst) |
| *parvus, a, um* (liten) | *minor, minus* (mindre) | *minimus, a, um* (minst) |
| *bonus, a, um* (god) | *melior, melius* (bedre) | *optimus, a, um* (best) |
| *malus, a, um* (dårlig) | *peior, peius* (verre) | *pessimus, a, um* (verst) |

Eksempler: *digitus minimus* (minste finger), *musculus latissimus dorsi* (ryggens bredeste muskel), *musculus longissimus*.

:::eksamen
- **Samsvarsbøyning**: *ligamentum (posteria / **posterius** / posterior)* (v2026); *ligamentum **anterius*** (h2025); *cornu **anterius*** (v2025); *ganglion **superius***, *ramus **posterior*** (h2024); *digitus **minimus*** (v2026, v2025).
- **Genitiv**: *ganglion superius → ganglii superioris / gangliorum superiorum* (h2023).
- **Bøy adjektivet**: superlativene *optimus* (h2025) og *minimus* (h2023) bøyes som vanlige 1+2-adjektiv.
- **Oversett**: *arteria cerebri anterior* (v2025), *ramus posterior nervi spinalis* (h2023).
:::

## Test deg selv

:::sjekk[Velg riktig: *ligamentum (posteria / posterius / posterior)* = bakre ligament.]
***posterius***. *Ligamentum* er 2n, og komparativens intetkjønnsform ender på *-ius*.
:::

:::sjekk[Gi gen pl av *ganglion superius* og forklar endelsen *-um*.]
*gangliorum superiorum*. Komparativer bøyes som konsonantstammer i 3. deklinasjon, ikke som i-stammer, og får derfor *-um*.
:::

:::sjekk[Hvordan bøyes superlativ, og hva er superlativ av *parvus*?]
Superlativ bøyes som 1+2 (*-us, -a, -um*). Superlativ av *parvus* er det uregelmessige *minimus, a, um*.
:::

:::sjekk[Hva er abl sg av *superior* (m), sammenlignet med is/e-adjektivet *brevis*?]
*superiore* (bare *-e*), mens *brevis* har *breve/i*. Komparativer er ikke valgfrie i-stammer.
:::
