## Adjektiv og partisipper

| Kasus | 1+2: m / f / n (*magnus*) | 3 is/e: m+f / n (*brevis*) | 3 én form + pres. part.: m+f / n (*duplex*, *recurrens*) | Komparativ: m+f / n (*superior*) |
|---|---|---|---|---|
| Nom sg | -us (-er) / -a / -um | -is / -e | *duplex*, *-ns* / samme | -ior / -ius |
| Akk sg | -um / -am / -um | -em / -e | -em / = nom | -iorem / -ius |
| Gen sg | -i / -ae / -i | -is | -is (*duplicis, recurrentis*) | -ioris |
| Abl sg | -o / -a / -o | -e/-i / **-i** | -e/-i (partisipp n: -i) | -iore |
| Nom pl | -i / -ae / -a | -es / **-ia** | -es / -(i)a (partisipp n: -ia) | -iores / -iora |
| Akk pl | -os / -as / -a | -es / -ia | -es / -(i)a | -iores / -iora |
| Gen pl | -orum / -arum / -orum | **-ium** | -(i)um (partisipp: -ium) | -iorum |
| Abl pl | -is | -ibus | -ibus | -ioribus |

Superlativ (*-issimus*, *minimus*, *optimus*) bøyes som 1+2.

## Baklengs: hva kan endelsen være?

| Endelse | Mulige former | Eksempler |
|---|---|---|
| **-a** | 1f (og 1m *prostata*) nom/abl sg; n nom/akk pl (2n, 3n, 4n-*ua*); 3n nom/akk sg på *-ma/-oma* | *vena* (nom/abl sg); *cerebra, corpora, genua* (nom/akk pl); *derma, sarcoma* (nom sg, gen *-matis*) |
| **-ae** | 1f gen sg **eller** nom pl | *aortae* |
| **-am / -as** | 1f akk sg / akk pl | *arteriam*, *aortas* |
| **-arum / -orum** | gen pl 1. / 2. dekl. (og 1+2-adjektiv) | *venarum*, *musculorum*. Felle: *tractorum* og *dolorum* er 3m gen pl (*tractor-um*), og *rabierum* er 5f gen pl (*-erum*) |
| **-i** | 2m/n gen sg **eller** 2m nom pl; abl sg av 3n i-stamme og 3.-dekl.-adjektiv | *colli* (gen sg), *nervi* (gen sg / nom pl), *reti*, *ovali* |
| **-o** | 2m/n abl sg | *ramo*, *cancro* |
| **-um** | 2m/n akk sg (og 2n nom); 3. dekl. gen pl; 4m akk sg | *umbilicum* (akk sg), *capitum* (gen pl), *partum* (akk sg) |
| **-os** | 2m akk pl (eller gresk nom sg *-os*) | *nucleos*, *umbilicos*, *humeros* |
| **-is** | **3. dekl. gen sg**; 1./2. dekl. **abl pl**; nom sg av *-is*-ord | *flexoris*, *oris* (gen sg); *encephalis, ramis, collis* (abl pl); *cutis* (nom/gen sg) |
| **-em / -e** | 3. dekl. akk sg / abl sg; 5f akk/abl sg; også nom sg av 3n i-stamme (*rete*) og n av is/e-adjektiv (*breve*) | *falcem, cutem* (akk sg); *ulcere, dolore, iride* (abl sg); *re* (abl sg) |
| **-es** | 3. dekl. nom/akk pl (og nom sg av noen 3m, *pes*); 5f nom sg og nom/akk pl | *dentes*; *pes*; *caries* |
| **-ium** | 3. dekl. gen pl (i-stamme / to konsonanter) | *meningium, mentium, dentium* |
| **-ibus** | 3. og 4. dekl. abl pl | *capitibus, ossibus, falcibus, manibus* |
| **-us** | 2m nom sg; 3n nom/akk sg (*corpus, ulcus*); **4m nom sg, gen sg, nom/akk pl**; **4n gen sg** | *nervus*; *cornus* (gen sg av *cornu*) |
| **-u** | 4m abl sg; 4n nom/akk/abl sg | *statu, situ, manu, partu*; *genu* |
| **-uum** | 4. dekl. gen pl | *manuum, sinuum, statuum* |
| **-ei** | 5f gen sg | *cariei, faciei* |
| **-erum / -ebus** | 5f gen pl / abl pl | *dierum, rabierum* / *rebus* |

:::husk
Fremgangsmåte for «angi tall og kasus»:
1. Finn ordet i ordlisten. Da vet du **deklinasjon og kjønn**.
2. Finn **stammen** (gen sg minus endelsen) og les av hva som er lagt til.
3. Slå opp endelsen i **riktig deklinasjonskolonne**. *-is* betyr noe helt annet i 2. dekl. (abl pl) enn i 3. dekl. (gen sg).
4. Er formen tvetydig, står den i oppgaven alene, og fasiten velger normalt den mest «typiske» kasusen. Eksempel: *colon* (2n) kan være nom eller akk sg – velg nom sg. (Former som *cancer* og *otitis* er entydige: bare nom sg, siden gen er *cancri*, *otitidis*.) (Dativ er ikke med i kurset, så former som *ossibus* = abl pl.)
:::

## Test deg selv

:::sjekk[Hvilken kasus og hvilket tall er *collis*? Og *flexoris*?]
*collis* = abl pl (*collum, i, 2n*: 2. dekl. abl pl *-is*). *flexoris* = gen sg (*flexor, oris, 3m*: 3. dekl. gen sg *-is*). Samme endelse, ulik deklinasjon.
:::

:::sjekk[Hvilken kasus er *cornus*, og hvorfor ikke nominativ?]
Gen sg. *Cornu, us* er 4n, og nominativ er *cornu*. Endelsen *-us* er genitiv entall.
:::

:::sjekk[Hvilken kasus og hvilket tall er *rabierum*?]
Gen pl av *rabies, ei, 5f* (5. dekl. gen pl *-erum*).
:::

:::sjekk[Hvilke former kan *-ae* være, og hvordan avgjør du det i et uttrykk?]
1f gen sg eller nom pl. Avgjør ved funksjon: etter et annet substantiv er det genitiv (*cancer prostatae*). Som hovedord først i uttrykket er det nom pl (*venae magnae*).
:::

:::sjekk[Hvilken kasus er *partum*? Hvilken er *partu*?]
*partum* = akk sg (4m, jf. *ante partum*). *partu* = abl sg.
:::
