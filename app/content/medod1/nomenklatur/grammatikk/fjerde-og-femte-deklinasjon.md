## 4. deklinasjon hankjønn: -us, -us

**Kjennetegn i ordlisten:** `-us, us, 4m`. Substantiv på ***-tus*** eller ***-sus*** er som hovedregel **avledet direkte av perfektum partisipp** (formelt verbets supinumstamme). Når ordet er substantiv, bøyes det etter 4. deklinasjon. Når det fungerer som perfektum partisipp, bøyes det etter 1+2.

| Kasus | status (tilstand) | Endelse |
|---|---|---|
| Nom sg | stat**us** | -us |
| Akk sg | stat**um** | -um |
| Gen sg | stat**us** | -us |
| Abl sg | stat**u** | -u |
| Nom pl | stat**us** | -us |
| Akk pl | stat**us** | -us |
| Gen pl | stat**uum** | -uum |
| Abl pl | stat**ibus** | -ibus |

:::husk
I 4. deklinasjon er ***-us* både nom sg, gen sg og nom/akk pl**. Det er adjektivet (eller sammenhengen) som avslører hvilken kasus det er: *situs **inversus*** (nom sg), *situs **inversi*** (gen sg eller nom pl), *situs **inversos*** (akk pl).
:::

### 4m-substantiv og perfektum partisipp med samme form

| Substantiv (4m) | Perfektum partisipp (1+2) |
|---|---|
| *aditus, us* = adgang, tilgang | *aditus, a, um* = gått til |
| *exitus, us* = utgang | *exitus, a, um* = utgått |
| *status, us* = tilstand | *status, a, um* = satt, plassert |
| *situs, us* = plassering, sted | *situs, a, um* = plassert, situert |
| *abortus, us* = abort, mislykket fødsel | *abortus, a, um* = avbrutt, forsvunnet |
| *partus, us* = fødsel | *partus, a, um* = født |
| *processus, us* = prosess, fremspring | *processus, a, um* = gått frem |

Også i ordlisten: *infarctus, us, 4m* (infarkt), *morsus, us, 4m* (bitt, stikk).

**Forskjeller og likheter (kollokvium 5):** Begge er avledet av verb. Perfektum partisipp må ha et substantiv å attribuere og **kan ikke starte et uttrykk**. Substantivet kan stå alene eller ha egne attributter. Formene er like i nom sg og akk sg, ellers er bøyningen forskjellig:

| Kasus | situs inversus (4m + 2m) | processus spinosus (4m + 2m) |
|---|---|---|
| Nom sg | sit**us** invers**us** | process**us** spinos**us** |
| Akk sg | sit**um** invers**um** | process**um** spinos**um** |
| Gen sg | sit**us** invers**i** | process**us** spinos**i** |
| Abl sg | sit**u** invers**o** | process**u** spinos**o** |
| Nom pl | sit**us** invers**i** | process**us** spinos**i** |
| Akk pl | sit**us** invers**os** | process**us** spinos**os** |
| Gen pl | sit**uum** invers**orum** | process**uum** spinos**orum** |
| Abl pl | sit**ibus** invers**is** | process**ibus** spinos**is** |

Flere uttrykk: *cancer in situ* (kreft på stedet, abl), *abortus provocatus* (fremkalt abort), *partus difficilis* (vanskelig fødsel), *status praesens* (nåværende tilstand), *status ante partum* (tilstand før fødselen, akk).

:::feil
- ***digitus, digiti, 2m*** (finger) er **2. deklinasjon**, ikke 4. Sjekk alltid genitiven i ordlisten.
- Noen få substantiv på *-us* er 4m og ikke 2m: ***sinus, us*** (bukt, hulrom), ***arcus, us*** (bue).
- ***manus, us, 4f*** (hånd) er **hunkjønn**, men bøyes likt med hankjønnsordene. Derfor heter det ***manus sinistra/dextra***, ikke *sinister*.
:::

| Kasus | manus (4f) | manus sinistra |
|---|---|---|
| Nom sg | man**us** | manus sinistra |
| Akk sg | man**um** | manum sinistram |
| Gen sg | man**us** | manus sinistrae |
| Abl sg | man**u** | manu sinistra |
| Nom pl | man**us** | manus sinistrae |
| Akk pl | man**us** | manus sinistras |
| Gen pl | man**uum** | manuum sinistrarum |
| Abl pl | man**ibus** | manibus sinistris |

## 4. deklinasjon intetkjønn: -u, -us

**Kjennetegn:** `-u, us, 4n`: *genu, genus* (kne), *cornu, cornus* (horn).

| Kasus | genu (kne) | genu dextrum |
|---|---|---|
| Nom sg | gen**u** | genu dextrum |
| Akk sg | gen**u** | genu dextrum |
| Gen sg | gen**us** | genus dextri |
| Abl sg | gen**u** | genu dextro |
| Nom pl | gen**ua** | genua dextra |
| Akk pl | gen**ua** | genua dextra |
| Gen pl | gen**uum** | genuum dextrorum |
| Abl pl | gen**ibus** | genibus dextris |

Intetkjønnsregelen gjelder: nom = akk, pl på *-a* (*genua*).

:::feil
Ikke bland ***genu, genus, 4n*** (kne) med ***genus, generis, 3n*** (art, slag). Formen *genus* kan være gen sg av *genu* eller nom/akk sg av *genus*.
:::

## 5. deklinasjon: -es, -ei (hunkjønn)

**Kjennetegn:** `-es, ei, 5f`.

| Kasus | res (sak, ting) | dies (dag) |
|---|---|---|
| Nom sg | r**es** | di**es** |
| Akk sg | r**em** | di**em** |
| Gen sg | r**ei** | di**ei** |
| Abl sg | r**e** | di**e** |
| Nom pl | r**es** | di**es** |
| Akk pl | r**es** | di**es** |
| Gen pl | r**erum** | di**erum** |
| Abl pl | r**ebus** | di**ebus** |

Ord: *caries, cariei* (råte), *facies, faciei* (ansikt, overflate), *rabies, rabiei* (galskap, raseri), *series, seriei* (serie), *species, speciei* (art), *fides, fidei* (tro).

Eksempler: *caries dentium* (tannråte), *per diem* (per dag, akk), *series brevis* (kort serie, f).

:::eksamen
- **Tall og kasus**: *cornus* (gen sg), *rabierum* (gen pl) (v2026); *situ* (abl sg), *cariei* (gen sg) (h2025); *statu* (abl sg), *faciei* (gen sg) (v2025); *sinuum* (gen pl), *partu* (abl sg) (h2024); *manu* (abl sg), *dierum* (gen pl), *partum* (akk sg) (v2024); *manuum* (gen pl), *re* (abl sg), *cornus* (gen sg) (h2023).
- **Genitiv sg/pl**: *genu → genus / genuum* (v2026); *status praesens → status praesentis / statuum praesentium* (h2024); *status → status / statuum*, *caries → cariei / carierum* (h2023).
- **Kjønn**: *manus* F, *aditus* M, *genu* N, *dies* F (ordlisten: 5f), *partus* M, *cornu* N, *series* F, *rabies* F, *facies* F.
- **Samsvarsbøyning / oversett**: *manus dextra*, *partus difficilis*, *status ante partum* (h2025); *manus sinistra*, *status gravis*, *cornu anterius* (v2025); *status gravis post commotionem cerebri* (h2023, v2025).
:::

## Test deg selv

:::sjekk[Hvilken kasus og hvilket tall er *statu*, *situum* og *cornus*?]
*statu* = abl sg, *situum* = gen pl, *cornus* = gen sg (4n *cornu, us*).
:::

:::sjekk[Velg riktig: *manus (dexter / dextra / dextrum)*.]
***dextra***. *Manus* er 4**f**, så adjektivet får hunkjønnsform.
:::

:::sjekk[Hva er forskjellen på *status* som substantiv og som perfektum partisipp?]
Substantivet (*status, us, 4m* = tilstand) bøyes etter 4. deklinasjon og kan starte et uttrykk. Partisippet (*status, a, um* = satt, plassert) bøyes som 1+2 og må attribuere et substantiv. Bare nom og akk sg m er like.
:::

:::sjekk[Gi gen sg og gen pl av *caries*.]
*cariei* / *carierum*.
:::

:::sjekk[Er *digitus* 2. eller 4. deklinasjon? Hvordan sjekker du det?]
2. deklinasjon (*digitus, i, 2m*). Genitiven i ordlisten er *-i*, ikke *-us*.
:::
