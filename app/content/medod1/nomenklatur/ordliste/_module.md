## Slik leser du et oppslag

Ordlisten er den du har tilgang til på eksamen – men **ingen latinsk ordbok**. Alt du skal bøye, må du altså kunne utlede fra de tre opplysningene i hvert oppslag: **nominativ entall, genitiv entall (helt eller som endelse) og deklinasjon + kjønn**. «Fra disse tre faller det meste på plass» (forelesning 28.–29.09).

| Oppslag | Hva det betyr | Slik bruker du det |
|---|---|---|
| `vena, ae, 1f` | substantiv, nom. *vena*, gen. *venae*, 1. deklinasjon, hunkjønn | Bøy etter 1. deklinasjon; adjektiv får feminin form (*vena magna*) |
| `nervus, i, 2m` | substantiv, gen. *nervi*, 2. dekl., hankjønn | Bøy etter 2m (*-us, -um, -i, -o …*) |
| `collum, i, 2n` | substantiv, gen. *colli*, 2. dekl., intetkjønn | Nom = akk; nom/akk pl. på *-a* |
| `cortex, icis, 3m` | gen. *corticis* → bøyningsstamme **cortic-** | Gen. sg. minus *-is* = stamme; legg til endelsene |
| `mors, rtis, 3f` | gen. *mortis* (bare slutten av genitiven er skrevet) | Fyll ut: mo**rtis** → stamme *mort-* |
| `status, us, 4m` | gen. *status*, 4. dekl., hankjønn | Bøy etter 4m (*statum, status, statu …*) |
| `caries, ei, 5f` | gen. *cariei*, 5. dekl., hunkjønn | Bøy etter 5f |
| `longus, 1+2` | adjektiv/partisipp etter 1. og 2. dekl. | Hankjønn som 2m, hunkjønn som 1f, intetkjønn som 2n |
| `brevis/e, is, 3` | adjektiv 3. dekl.: m+f *brevis*, n *breve*, gen. *brevis* | is/e-adjektiv – alltid gen. pl. *-ium* |
| `simplex/ex, icis, 3` | adjektiv 3. dekl. med lik nominativ i alle kjønn (*simplex*), gen. *simplicis* | Stamme *simplic-* |
| `superior/ius, ioris, 3` | komparativ: m+f *superior*, n *superius*, gen. *superioris* | Bøyes som konsonantstamme (abl. *-e*, n pl. *-a*, gen. pl. *-um*) |
| `recurrens/ns, ntis, 3` | presens partisipp: nom. *recurrens* i alle kjønn, gen. *recurrentis* | i-stamme i intetkjønn |

:::husk
- **Tallet** = deklinasjon (1–5). «1+2» eller bare «3» uten kjønn = **kjønnsfleksibelt ord** (adjektiv/partisipp).
- **Bokstaven** (m/f/n) = substantivets faste kjønn. Det er *kjønnet*, ikke deklinasjonen, som bestemmer formen på adjektivet: *prostata, ae, **1m*** → *prostata aeger* (ikke *aegra*).
- **Genitivsendelsen** viser bøyningsstammen. I 3. deklinasjon kan stammen være annerledes enn nominativ: *foramen → foramin-*, *corpus → corpor-*, *os → oss-* / *or-*.
:::

:::feil
Oppslagene er skrevet i forkortet form, og noen er litt uregelmessig skrevet i PDF-en. Les dem slik:
- `mors, rtis` og `pars, rtis` = *mortis*, *partis*.
- `abdomen, minis`, `foramen, minis`, `lumen, minis`, `homo, minis` = *abdominis*, *foraminis*, *luminis*, *hominis*.
- `biceps/ceps`, `triceps/ceps`, `duplex/ex`, `simplex/ex` = samme nominativ i alle kjønn (*biceps*, *duplex*).
- `perforans/ns` osv. = samme nominativ i alle kjønn (*perforans*).
- `minor/us, oris` = m+f *minor*, n *minus*, gen. *minoris*. `longior/ius, oris` og `maior/ius, oris` = gen. *longioris*, *maioris*.
- `ovalis/e, is 3` mangler et komma – det er et vanlig is/e-adjektiv.
- Det finnes to `os`: *os, ossis, 3n* = bein og *os, oris, 3n* = munn. Bare genitiven skiller dem.
- Noen kjønn må du bare pugge: *prostata* er **1m**, *manus* er **4f**, *dies* står som **5f** i ordlisten, *testis* er **3m**.
:::

:::eksamen
Eksamen (2023–2026) har faste oppgavetyper i latin: *angi kjønn*, *angi tall og kasus*, *fyll inn riktig samsvarsbøyning*, *bøy et adjektiv i alle kjønn og kasus*, *angi genitiv entall og flertall* og *oversett til latin*. Nesten alle ordene som brukes, står i denne listen. Les oppslaget nøye. Se [endelsesoversikten](/medod1/nomenklatur/grammatikk/endelsesoversikt) for å gjenkjenne en bøyd form.
:::

Kolonnen «Type» er lagt til her som hjelp; den er utledet fra oppslaget. Rekkefølgen innen hver bokstav følger PDF-en, som ikke er helt alfabetisk.
